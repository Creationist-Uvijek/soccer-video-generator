# Soccer Video Generator

This Streamlit app automatically creates educational soccer explainer videos for kids using AI.

## How to Run on Streamlit Cloud

1. Fork this repo to your GitHub account.
2. Go to https://streamlit.io/cloud and deploy the app.
3. Add the following to your Streamlit Secrets:
```
[openai_api_key]
openai_api_key = "your-api-key-here"
```
4. Upload a royalty-free music file named `alone-296348.mp3` in the root directory.
